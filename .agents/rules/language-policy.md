# Language & Communication Policy (`language-policy.md`)

This workspace strictly adheres to a dual-language policy:

1. **User Communication (Spanish)**:
   - All conversational responses, explanations, walkthroughs, status updates, and interactive user prompts MUST be delivered in **Spanish** when requested by the maintainer.
   - Tone should be professional, collaborative, pragmatic, and direct.

2. **Repository Artifacts (100% English)**:
   - **All repository files and code artifacts MUST be written entirely in English**.
   - This includes:
     - Python source files, modules, classes, methods, functions, variables, and type hints.
     - Docstrings, inline code comments, and docblocks.
     - Terminal output, Rich console panels, CLI log messages, and error strings.
     - Markdown documentation (`README.md`, `SPECIFICATION.md`, `AGENTS.md`, and skills).
     - Git commit messages (`feat: ...`, `fix: ...`, `test: ...`).
     - Test descriptions and assertions.
     - HTML/CSS UI templates and generated report dashboards.
