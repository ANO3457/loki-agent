# v1.0.0

Initial public release of LOKI.

## Added
- Core sandbox engine on Playwright with a live crash sniffer.
- Synthetic chaos persona engine: `RageClicker`, `NoviceChaotic`, `NetworkTormentor`, `Adversary`.
- Swarm mode to run all personas in coordinated assault waves.
- Interactive conversational QA terminal (`loki chat`).
- Guided journey recorder and journey blueprint synthesizer.
- `loki replay` for deterministic incident re-runs with video playback.
- Deterministic incident reporter and automated repro script generator.
- Automated HTML visual report generator (`loki report`).
- AI-powered business rules evaluation with a live scorecard.
- AI brain and `loki fix` command powered by Gemini.
- Workspace scanner and `loki init` command.
- `loki run` auto-resolves target URL and settings from `config.yaml`.
- Network traffic capture and sanitization (`NetworkScrubber`, HAR reporter).
- CI/CD quality gate (`CIGate`) with exit codes and a GitHub Actions workflow.
- `AGENTS.md` and native `.agents` skill for universal AI agent onboarding.
- Cross-platform standalone binaries via PyInstaller and a release workflow.
