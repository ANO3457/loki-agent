# v1.8.0

## Added
- **In-Interface Self-Update Notification**: When launching the interactive chat REPL (`loki` or `loki chat`), LOKI checks GitHub Releases in the background (with local 1-hour TTL caching) and renders a prominent update panel if a newer version is available, displaying the exact `uv` upgrade commands.
- **Interactive `/update` Slash Command**: Upgrade LOKI directly from inside the conversational QA chat session via `uv tool upgrade loki-chaos-agent` (or git reinstall fallback) without exiting the REPL.
- **CLI Update Commands**:
  - `loki update`: Check and execute upgrade via `uv` directly from terminal.
  - `loki update --check`: Check whether a newer release exists without modifying the installation.
  - `loki version --check`: Check GitHub releases and compare against the currently installed version.
- **Autonomous Multi-Agent Operating System (`.agents/` & `AGENTS.md`)**:
  - Comprehensive architectural constitution in root `AGENTS.md` specifying universal invariants, memory hierarchy, and tooling protocols.
  - Modularized rules under `.agents/rules/` covering coding standards, git atomic cadence, language policies, and security/privacy scrubbing.
  - Declarative subagents under `.agents/agents/` for `chaos-tester`, `code-healer`, `qa-auditor`, and `persona-architect`.
  - Progressive skills runbooks under `.agents/skills/` for chaos operations, autonomous healing, and packaging/release workflows.
  - Cross-assistant bridges for Claude Code (`CLAUDE.md`) and GitHub Copilot (`.github/copilot-instructions.md`).

## Fixed
- Fixed Windows terminal `charmap` codec crash (`UnicodeEncodeError`) during banner rendering by enforcing UTF-8 output stream reconfiguration with fallback character replacement.
